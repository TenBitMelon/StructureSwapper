# Structure Swapper

A simple plugin that can store and swap built structures in the same location! 
The idea is to make it easier to reuse builds and switch between saved states
in the same area with an intuitive in game menu!

You put down special structure blocks and open a menu to select or place saved structures. 
The plugin reads vanilla structure NBT files from the first world's 
`generated/minecraft/structures` folder for convenient use with existing structure blocks. 
It has a section for pinned and recently used structures. The bounding box is nicely colored with
particle outlines and there are placement alignment settings to get things in place.
The edges of the bounding box are clickable controls for resizing and moving the selected area.
